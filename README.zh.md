# 思考过程机器翻译（自选模型）

基于 DeepSeek Harness 官方 MIT 版思考过程机器翻译，保留展开后翻译、查看原文、失败重试和 Session 译文缓存。默认使用 Bing，也可选择 Google、可用的 DeepSeek 原生服务，或 DSH 中已配置的文本模型。当前版本对应 DSH `0.2.2-rc.3` 的插件接口。

1. 在「插件 → 发现 → yu1745 的 DSH 插件」安装本插件。如果官方版已启用，先停用官方版。两个插件会占用相同的翻译服务和思考区。
2. 在 DSH 模型设置中配置所用的 API、凭据和文本模型。
3. 打开本插件的设置，把翻译服务切换为「已配置的模型」，选择模型和目标语言并保存。目标语言填 `auto` 时跟随界面，也可填 `zh`、`en` 或 `ja` 等语言代码。
4. 展开会话中的思考过程即可开始翻译。可用「查看原文」切回原文。

仅将待翻译片段发给所选模型。思考片段可能含有代码或对话细节，第三方 API 的隐私政策和计费规则适用。切换目标语言或模型后可能需要重新翻译。
